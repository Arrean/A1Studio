# A1Studio

Windows 建筑 A1 展板排版工作台，面向建筑学校展板制作。当前版本为 **0.3.4-preview.1（公开预览版）**，应用内版本 **0.3.4**。

## 下载

前往 [Releases](https://github.com/Arrean/A1Studio/releases) 下载：

- **A1Studio-0.3.4-Setup.exe**：直接安装。
- **A1Studio-0.3.4-preview.1-win-x64.zip**：安装器、使用指南、合成 PDF 样本、反馈模板与第三方许可合集，**不是免安装版**。
- SHA256SUMS.txt：文件校验清单。

目标 Windows 10 2004+ / Windows 11 x64，随包携带 .NET 8.0.32，无需 Visual Studio 或 .NET SDK。Windows 11 干净机实测待补。安装器未代码签名，请核对下载来源和 SHA256。升级前保存、关闭软件并备份工程；安装后在“文件 → 关于 A1 Studio…”确认版本和路径，旧任务栏入口需要重新固定。

## 功能

- A1 横竖版、多页管理、装订边、缩放与中键平移、沉浸式翻页。
- 毫米坐标、源/目标比例与裁切；多选、对齐、等距、组合、90° 旋转及撤销。
- PDF 多页、静态 SVG、图片、文字与艺术字、项目字体，自包含项目及自动恢复。
- 带预览的多页矢量 PDF 导出、sRGB 工作流与高清区域预览。
- 三套规则布局、候选预览/应用与自定义模板。
- 本机 AutoCAD/Revit 图纸快照接入，可选在线 AI 排版诊断。

## 已知限制

这是预览版，完整验收尚未完成。0.3.4 已执行 37 组离线回归；新构建干净机、性能、实际 DPI 和取消专项尚未完整重测，不继承旧版成绩。最终 PDF 写入取消本轮跳过，仍待验证。

AutoCAD/Revit 2018—2027 有按年份桥接，未逐年完成真实主机验收；需要自己的相应软件，Revit 2018—2021 转 PDF 还需 AutoCAD。普通 PDF 源比例须用户确认，默认 A4 适配会改变实际摆放比例。长期内存、完整字体及实际打印待补，未声明 PDF/X 或 CMYK 正式印刷认证。

AI 目前提供诊断与建议，不自动修改布局。在线调用会向配置的服务发送对象名称、文字、位置、尺寸和比例；默认勾选的页面缩略图包含可见内容，可取消勾选，不直接发送原始素材文件。

详细限制和第三方许可随下载包提供。建议先用工程副本试用并备份。
